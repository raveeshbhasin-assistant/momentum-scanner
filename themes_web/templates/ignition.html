Ignition Watch

Every stock in the S&P 500 + 400 that fires the ignition signal becomes a tracked position: bought at the next open, held while the breakout is intact, and flagged sell when the ignition fails. The ledger is rebuilt from prices on every run, so a missed day can't lose an event.
{% if ig %} {% set s = ig.summary %} {% set b = ig.backtest %} {% set x = ig.exit_research %}
Buy signal: 5-day return > +12% on 21-day volume > 1.5× its 6-month average, 50-DMA above 200-DMA. After a fire {{ b.p_plus40_63d }}% went on to +40% within 3 months (vs {{ b.p_plus40_baseline }}% of all stocks).
Sell signal: a close below the pre-ignition base (the close 5 sessions before the fire — the whole breakout week given back); sell at the next open. Of {{ x.rules_tested }} exit rules tested on {{ x.trades }} trades it was the only one near the top in training, holdout and live data.
Falling off the list is not a sell. {{ x.p_off_next_day }}% of fires are off the list the next day; those still returned +{{ x.dropoff_fwd63 }}% over 3 months (vs +{{ x.baseline_fwd63 }}% for all stocks). Selling on drop-off was the worst rule tested. Re-fired (a fresh ignition) is the strongest hold state; edge expired (63 sessions without a re-fire) means the signal's edge window is over — a review flag, not a sell. A position with no re-fire for 12 months is closed as aged out.
6-month review (optional, flag only): 126 sessions after entry, a position that is up but by less than +30% is flagged — "take the profit or keep holding?". The sell line sits ~14% below entry, so the rule above only ever sells at a loss; this is the one take-profit rule that held up across training, holdout and live data (about half as many "was up 20%, sold at a loss" trades, better median), but it costs ~6 points of average return per trade, so it doesn't close positions here. Study.
2× cap (optional, flag only): a winner that has grown to 2× or more of an equal share of the held positions (assuming equal dollars at each entry) is flagged with how much to sell to get back to 2×. In a 2016-26 portfolio test a hard 2× cap cut the worst drawdown at nearly every portfolio size for about 0.5 points of annual return. It is risk control, not a return edge.
